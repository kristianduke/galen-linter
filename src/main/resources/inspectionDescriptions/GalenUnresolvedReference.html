Reports object and object-group references that do not resolve to a declaration in scope.

Galen puts an imported file's objects into the importing spec — ImportProcessor merges objects as well as specs — so resolution follows this file and everything it imports, transitively. A wildcard declaration such as menu_item-* satisfies a reference to menu_item-3.

When the name is declared in a file that is not imported, the message says so and names the file, since a forgotten @import is the usual cause.

Why this is a warning rather than an error

Resolution can come up empty without anything being wrong: an @import may point at a classpath resource that the IDE cannot see, and a JavaScript rule can contribute objects at run time through addObjectSpecs. Names built from ${...} expressions are never reported at all.
