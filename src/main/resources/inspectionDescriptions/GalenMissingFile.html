Reports a file referenced by @import, @script, component, image file or filter mask that cannot be found.

Paths resolve against the directory of the file containing them, matching Galen, which builds its context path from the parent of the file currently being processed.

Reported as a warning because Galen resolves through GalenUtils.findFileOrResourceAsStream, so a path that is absent from the filesystem may still be a valid classpath resource.

@lib is never reported: it names a library bundled inside the Galen distribution rather than a path on disk.
