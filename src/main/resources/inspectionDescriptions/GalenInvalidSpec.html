Reports spec arguments that Galen's own parser rejects. A file containing any of these cannot run.

Each rule mirrors a specific check in Galen's source:

  • GL301 — unknown spec name. SpecReader registers exactly 21 specs.
  • GL302 — aligned is missing its edge, or pairs an edge with the wrong direction. horizontally accepts all, top, bottom, centered; vertically accepts all, left, right, centered.
  • GL303 — an object is declared absent alongside a spec that requires it to be visible, so the pair can never pass.
  • GL309 — a count range was given a px unit; it takes a plain number.
  • GL318 — near with no side. SpecNearProcessor throws when no location is supplied, so a bare distance is invalid.
  • GL319 — a side other than left, right, top or bottom. Matching is case sensitive.
  • GL320 — an aligned direction other than horizontally or vertically.
  • GL322 — on without the word edge.
  • GL323 — a corner combining two opposite sides, such as on top bottom edge.

Arguments supplied by a ${...} expression are skipped, since their value is only known at run time.
