Reports spec arguments that Galen accepts but that are almost certainly mistakes.

These are not syntax errors — every one of them parses and runs. That is precisely why they are worth reporting: the spec quietly does something other than what was intended.

  • GL305 — the argument to matches is not a valid Java regular expression. It is compiled at run time, so the failure surfaces late.
  • GL306 — an unknown text operation. SpecTextProcessor accumulates any unrecognised word as an operation, so text lowercse is "x" runs and performs no case folding at all. Also reports lowercase and uppercase on the css spec, which does not support them.
  • GL310 — an image contrast level outside 0–258.
  • GL311 — denoise applied as filter rather than map-filter. It only operates on the black-and-white comparison map.
  • GL312 — an image spec with no file sample, leaving nothing to compare against.
  • GL313 — an unknown image option or filter name.
  • GL315 — a relative property other than width or height. ExpectRange accepts any path without validating it.
  • GL316 — the same spec declared twice on one object.
