Reports lines inside an @objects block that look like object definitions but are silently parsed as comments.

Galen decides that a line is a comment by testing whether its trimmed text starts with #, and it does so before any structural parsing. An object whose name begins with # is therefore never defined, and every later reference to it fails at run time with no syntax error pointing at the cause.

Example


@objects
    #footer   div.footer     
    header    div.header

Because prose comments are perfectly normal inside @objects, this inspection only fires when a line has no space after # and contains at least two whitespace-separated fields.
