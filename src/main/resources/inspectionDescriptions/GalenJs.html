Reports problems in the JavaScript embedded in ${...} expressions and @script blocks.

This is a fallback for IDEs without JavaScript support — IntelliJ IDEA Community bundles none. When a JavaScript plugin is installed, the embedded code is injected and analysed properly, and this inspection stands down entirely rather than duplicating it.

  • GL701 — .name called as a method. It is the one page-element member that is a property; every other one (.width(), .isVisible()) is a call, so find("x").name() throws at run time.
  • GL702 — an unterminated string literal.
  • GL703 — a near-miss of a Galen API function, such as isVisble for isVisible. Only reported when the name is called and differs by a single character, since a @script file may define any function it likes.
  • GL704 — an unbalanced bracket, brace or parenthesis. Checked only inside a ${...} expression, which must be self-contained; a @script body is one program spread across lines, so a brace opened on one line is legitimately closed on another.

Anything requiring scope or type analysis — undefined variables, wrong argument counts — is deliberately not reported. Without a parser those cannot be judged reliably, and a false positive on working JavaScript is worse than a missed one.
